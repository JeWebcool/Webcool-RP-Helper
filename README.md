# ⚖️ Whistle Helper for Nova RP

**Whistle Helper** — это быстрое и удобное приложение для игроков, адвокатов и сотрудников государственных структур на сервере Nova RP. Помогает мгновенно находить нужные статьи законов прямо во время игры.

---

## 🌟 Основные возможности

* **Законодательная база под рукой:** Быстрый поиск по статьям.
* **Глобальные горячие клавиши:** Вызов хелпера поверх всех окон по нажатию клавиши (по умолчанию `Alt + W`).
* **Автоматические обновления:** Проверка актуальности версии и автоматическое обновление при выходе патчей.
* **Минималистичный интерфейс:** Легкий и современный дизайн в стиле Spotlight, не нагружающий систему.

---

## 🛡️ Безопасность и Открытый Исходный Код (Open Source)

Многие игроки с опаской относятся к сторонним программам. В Whistle Helper всё максимально прозрачно:
1. **Открытый код:** Весь исходный код доступен в папке `src/`. Вы можете лично изучить каждую строчку перед запуском или сборкой.
2. **Никаких скрытых процессов:** Программа работает исключительно с локальными `.json` файлами законов и обращается только к официальному репозиторию GitHub для проверки обновлений.
3. **Чистота от вирусов:** Сборка проекта полностью безопасна, а редкие срабатывания некоторых антивирусов — это известный ложноподобный детект компилятора PyInstaller.
